How to install this in Gmail

  1. Select everything inside the box below (click once inside it, then Cmd/Ctrl+A, then Cmd/Ctrl+C).
  2. In Gmail: Settings (gear icon) → See all settings → General → Signature → Create new.
  3. Click inside the signature editor and paste (Cmd/Ctrl+V). It should keep the colours and layout.
  4. Set it as your default signature for new emails and replies, then Save changes at the bottom.
